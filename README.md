# Single-Page CV (HTML Only)

Project URL: https://roadmap.sh/projects/single-page-cv

A clean, responsive single-page Curriculum Vitae (CV) built strictly with semantic HTML5, SEO meta tags, Open Graph (OG) tags, and favicon.

## Features & Submission Checklist
- [x] **Semantically Correct HTML Structure**: Built using semantic elements including `<main>`, `<header>`, `<section>`, `<article>`, `<address>`, `<time>`, `<h1>`-`<h3>`, and `<ul>`.
- [x] **Single-Page Layout**: Sections for Education, Skills, Work Experience, and Links.
- [x] **SEO Meta Tags**: Title, description, keywords, author, robots, and canonical URL in `<head>`.
- [x] **Open Graph (OG) & Twitter Cards**: Tags for social media sharing.
- [x] **Favicon**: Embedded SVG favicon linked in the `<head>`.
- [x] **Clean Visual Alignment**: Matches the design specification with clear hierarchy and typography.
